### 5.5 为什么原生 Mean Validation Dice 是 0.162488

63 个阳性病例全部纳入，131 个有 FP 的阴性病例 Dice=0，29 个 GT 与预测均为空的
阴性病例 Dice=NaN，原生 nanmean 排除这些 NaN。均值实际分母为 **194**：

```text
native foreground mean Dice
= sum(63 positive Dice) / (63 + 131)
= 0.162488060729
```

因此它同时受阳性分割和阴性 FP 影响，不能称为“223 例平均 Dice”，
也不能代替阳性宏平均 Dice。这不是报告计算冲突。

## 8. 观察、限制与后续

1. 训练完成且有 57/63 阳性病例产生正确重叠，未出现阳性空预测；不能把该 run 描述为整体全背景失败。
2. 阳性体素召回仍仅 51.86%，相当比例 GT 未覆盖；宏平均 0.500 不代表病灶边界已经充分恢复。
3. 131/160 阴性病例产生前景，必须与阳性覆盖一起评估。阴性风险不能用提高阳性 Dice 抵消。
4. 只有一折、一个 seed、一次 final 整例验证；没有外部测试或 run-to-run 方差证据。
5. best 是 patch EMA 选择，尚无 best 整例指标，不声称它更好。
6. 原始影像难度、物化几何、标签源、分辨率和概率分布的因果归属尚未确定。
