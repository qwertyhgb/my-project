### 2.1 阳性采样的具体含义

batch size=2，最后一个槽位从训练阳性病例集合选取，使用原生前景中心裁剪；
另一个槽位从全部训练病例均匀选取。因此每个 batch 的采样阶段保证至少一个病灶中心 patch，
不等于两个槽位均阳性，也不保证空间增强后每个 patch 都保留相同病灶体积。
验证 loader 保持原生采样，不使用验证标签重平衡。

### 2.2 随机性与复现边界

run-config 确认 Python / NumPy / torch / CUDA 显式 seed 已应用。
显式 seed 不保证 bitwise determinism：多进程增强顺序、CUDA 行为及中断后随机状态恢复均可能影响轨迹。
本次包含一次中断续训，不应声称与不中断运行逐步等价；单 run 无法估计 run-to-run 方差。
run-config 没有训练时 Git commit 字段，不能仅由当前仓库 HEAD 证明训练全程源码版本完全相同。

## 6. Failure-mode解释与证据边界

1. **完全漏检仍是主要问题**：25/63阳性病例TP=0，其中22例完全没有预测。
   这支持把漏检保留为后续方法的核心终点；不证明某个尚未训练模块能解决它。
2. **覆盖不足**：阳性 pooled voxel recall=0.386065，FN=355881；预测总体积约为参考的一半。
   这些是病例/体素汇总，不能推出每个被找到的病灶都缺失同样比例边界。
3. **存在明确FP代价**：24/160阴性有预测，累计40251个FP体素。
   高阳性voxel precision=0.778558不能掩盖阴性FP；需后续组件/空间分析才能解释其位置和数量。
4. **训练过程与最终指标必须分开**：best EMA=0.588188不等于整例Dice；final整例primary为0.295192。
5. **尚不能进行A1/A2选型**：本报告只记录A1，未提供匹配A2结果或配对比较。
   不声称loss优劣，不引用其他实验文档作本实验的内部结果。
6. **单seed且中断续训**：不估计跨run方差、不声称完全复现；后续匹配设置需披露中断历史。
7. summary检查通过不等于掩膜geometry/count重算通过。本次没有重跑full评估、阈值选优或预测后处理。
