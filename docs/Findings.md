# Findings

跨实验的观察、问题优先级与下一步判据。本文档是**横向汇总**，不含单实验详情——单实验的配置、
运行事实与完整误差结构见 `docs/experiments/`。

所有数字均取自各实验自己的 `validation/summary.json` 与训练日志，并已独立复算核对。

---

## 1. 核心判断

四次完成训练（N0 / `image_gate` / `positive_sampling` / `image_gate_positive_sampling`）反映出的
首要问题**仍不是「假阳性太多」**，而是：

1. **病灶漏检严重**，尤其对小病灶不敏感；
2. **即使检出，也常只分出病灶核心**，范围明显不足。

四次之间的进展是不对称的：

| run | 改动 | 完全漏检 | 有重叠 | 阳性 Dice 中位数 | 阴性假阳病例 |
|---|---|---:|---:|---:|---:|
| N0 | — | 34/63 | 29/63 | 0 | 11/160 |
| `image_gate` | 输入级序列门控 | 33/63 | 30/63 | 0 | 17/160 |
| `positive_sampling` | 每批固定一个阳性病灶 patch | **21/63** | **42/63** | 0.2372 | 30/160 |
| `image_gate_positive_sampling` | 序列门控 + 阳性采样 | 23/63 | 40/63 | **0.2888** | **27/160** |

- **【原生采样分支的历史对照：N0 ↔ `image_gate`】** 两者同为原生采样，`image_gate` 只解决了
  **收敛慢**（前景学习延迟）的问题，没有真正突破**最终分割上限**：完全漏检 34 → 33 例，
  中位数 Dice 仍为 0。该结论**只在原生采样条件下成立**，不得外推到阳性采样分支，也不是
  「所有已完成实验」的一般结论。
- **【训练采样对照：N0 → `positive_sampling`】** 同网络、同 FLCE 损失、同划分，主要差异是
  训练采样。`positive_sampling` **第一次在漏检上取得实质改善**（漏检 34 → 21、有重叠 29 → 42、
  中位数 Dice 0 → 0.2372），但它同时把工作点推向更「激进」的一侧：**阴性假阳病例 11 → 30**，
  且 `all_prediction_voxel_precision`（0.6796）**低于** `image_gate`（0.7270）。
  该观察不能归因于 gate 或解剖条件（此 run 不含 gate / PZ-TZ），且仍是单次运行。
- 四个 run 的 **micro Dice 都停在 0.52–0.55**（0.5212 / 0.5244 / 0.5449 / 0.5397），体素召回率也只在
  0.39–0.43 之间：整体病灶体素匹配度几乎没有变化 ⇒ **改训练采样能减少「整例漏检」，但尚未突破
  「检出后覆盖不全」这一上限**（见第 3.4 节）。
- **【RQ1 公平匹配比较：`positive_sampling` ↔ `image_gate_positive_sampling`】** 两者同为
  FLCE + 阳性采样、同分划，唯一结构差异是输入级 image gate。配对结果：macro Dice 0.3068 → 0.2991
  （配对均值 delta **−0.0077**，CI95 **[−0.0540, +0.0403] 含 0**），完全漏检 21 → 23、有重叠
  42 → 40；但 `positive_voxel_precision` 0.7522 → **0.8341**、阴性假阳病例 30 → **27**。
  即**在本 fold 的这次运行中未观察到明确的分割增量效用，看到的是工作点向更保守一侧移动**
  （precision↑、假阳↓、漏检略↑）。完整指标与判据见 §3.10；受单次运行与无随机种子限制，
  **不得**表述为「gate 无效」或「gate 降低性能」。

因此当前的首要矛盾可以更精确地表述为：

> **让小病灶与困难病灶从「完全没找到」变成「找到并覆盖足够范围」，同时不把假阳病例继续推高。**

## 2. 问题优先级

口径说明：

- **有任意重叠预测** = 逐病例 `Dice > 0`；**完全无重叠** = 63 − 该数
- **体素召回率** = 全部阳性病例的 `ΣTP / Σn_ref`
- **体素精度** = `all_prediction_voxel_precision` = `ΣTP / 全部 223 例的 Σn_pred`
  （**分母包含阴性病例的假阳体素**）
- **阳性病例体素精度** = `positive_voxel_precision` = `ΣTP / (ΣTP + ΣFP)`，仅阳性病例（论文核心口径）
- **micro Dice** = 仅在阳性病例上合并计算的 pooled Dice
- **阳性/阴性病例假阳性体素** = 分别在阳性 / 阴性病例子集上求和的 `ΣFP`
- **`pred/ref`** = 预测体积 ÷ 标注体积；`< 1` 表示欠分割，`> 1` 表示过预测

| 问题 | N0 | `image_gate` | `positive_sampling` | `image_gate_positive_sampling` | 判断 |
|---|---:|---:|---:|---:|---|
| 阳性病例有任意重叠预测 | 29/63（46.0%） | 30/63（47.6%） | **42/63（66.7%）** | 40/63（63.5%） | 采样改动第一次把它推过 2/3；但仍有约 1/3 完全未检出 |
| 阳性病例完全无重叠 | 34/63 | 33/63 | **21/63** | 23/63 | 仍是**最主要问题**；采样改动后出现实质下降（−13），加入 image gate 后小幅回升（+2） |
| 阳性病例 Dice 中位数 | 0 | 0 | 0.2372 | **0.2888** | 前两次有一半以上阳性病例 Dice 为 0；阳性采样两次运行都不再如此 |
| 阳性病例平均 Dice（macro，论文主指标） | 0.1975 | 0.2162 | **0.3068** | 0.2991 | 采样改动带来最大提升；image gate 在该口径下未继续提升（配对 delta −0.0077，CI 含 0，见 §3.10） |
| 阳性病例 micro Dice | 0.5212 | 0.5244 | 0.5449 | 0.5397 | **四者几乎持平**（0.52–0.55）⇒ 体素级匹配度没有被突破 |
| 体素召回率 | 0.4052446901 | 0.3927065651 | **0.4271243048** | 0.398901 | 四次 run 之间基本没动（0.39–0.43）⇒ 仍只覆盖约四成病灶体素 |
| `positive_voxel_precision`（仅阳性病例，论文核心口径） | 0.7301160557 | 0.7889982982 | 0.7522414542 | **0.834071** | 阳性采样下的 image gate 把该口径推到四者最高（相对参照臂 +0.0818） |
| `all_prediction_voxel_precision`（分母含阴性假阳体素） | 0.6730222670 | 0.7269530951 | 0.6796059476 | **0.746372** | 同一现象：加上 image gate 后超过 `image_gate`（0.7270）成为最高 |
| 阴性病例出现预测 | 11/160 | 17/160 | **30/160** | 27/160 | 采样改动把假阳病例推高，加入 image gate 后回落 3 例（−3），但仍远高于 N0 |
| 阴性病例假阳性总体积（体素） | 27,294 | 24,625 | 35,178 | **32,575** | 与病例数同向回落（−2603），但仍高于 N0。平均每例假阳体积持续下降（2481 → 1449 → 1173 → 1206 体素），**中位数非单调**（1464 → 274 → 534 → 253），细节见 3.5 节 |
| 阳性病例假阳性体素（体素） | 86,833 | **60,878** | 81,547 | 46,001 | 阳性采样下的 image gate 把阳性区内假阳压到四者最低 |

> 新增的 `image_gate_positive_sampling` 列与 `positive_sampling` 是 RQ1 的**公平匹配对**（同损失、
> 同采样、同分划，唯一结构差异是输入级 image gate）；两者之间的比较与配对区间见 §3.10。
> 它与 `image_gate` 列**不可比较**（采样不同），与 N0 列也不可比较。

> **不要把 `positive_sampling` 的 `all_prediction_voxel_precision` 读成"精度变差"或"精度变好"**：
> 它相对 N0 是 **+0.0066（略升）**，但相对 `image_gate` 是 **−0.0473（明显更低）**。
> 该 run 的真实代价体现在**假阳病例数**（11 → 30）而不是这个比值上 —— 因为它的阳性区假阳体素
> 反而下降了（86,833 → 81,547），抵消了阴性假阳的增加。

## 3. 逐条诊断

### 3.1 最严重的是漏检，而不是普通的边界误差

N0 有 **34** 个阳性病例完全没有重叠，`image_gate` 仍有 **33** 个；`positive_sampling` 降到
**21** 个 —— 这是三次里唯一一次实质下降。但 21/63 仍意味着**每三个阳性病例就有一个完全没有
定位到病灶**。

在 N0 与 `image_gate` 下，阳性病例 Dice 中位数都是 **0**（过半病例为零），整体性能被完全漏检
主导。`positive_sampling` 把中位数抬到 **0.2372**，但漏检病例仍单独贡献 21 个 0 分：
只看有重叠的 42 例，逐例平均 Dice 是 **0.4602**；21 个 0 分把它拉到 **0.3068**。

因此当前的主要矛盾仍然是：

> **病灶有没有被发现，而不是发现后边界能不能再精修几个像素。**

采样改动减轻但没有消除这个矛盾。

### 3.2 小病灶问题非常明显

以「每例标注阳性体素总数」作为**病灶负荷代理**，将 63 个阳性病例按四分位分组
（检出定义为 `Dice > 0`；切分为 16 / 16 / 16 / 15，边界取自排序后的标注体素数）：

| 病灶负荷（体素） | n | N0 检出 | `image_gate` 检出 | `positive_sampling` 检出 |
|---|---:|---:|---:|---:|
| 190–965 | 16 | 3/16 | 4/16 | **7/16** |
| 1128–2459 | 16 | 7/16 | 7/16 | **12/16** |
| 2624–7001 | 16 | 9/16 | 9/16 | **11/16** |
| 7724–123055 | 15 | 10/15 | 10/15 | **12/15** |

各组的逐例平均 Dice：

| 病灶负荷（体素） | N0 | `image_gate` | `positive_sampling` |
|---|---:|---:|---:|
| 190–965 | 0.0518 | 0.1017 | **0.2207** |
| 1128–2459 | 0.1527 | 0.1445 | **0.2625** |
| 2624–7001 | 0.1797 | 0.2161 | **0.2959** |
| 7724–123055 | 0.4198 | 0.4149 | **0.4576** |

累积视角更直观：

| 病灶负荷上限 | 例数 | N0 检出 | `image_gate` 检出 | `positive_sampling` 检出 |
|---|---:|---:|---:|---:|
| ≤ 500 体素 | 6 | **0/6** | **0/6** | **1/6** |
| ≤ 1000 体素 | 16 | 3/16 | 4/16 | **7/16** |
| ≤ 2000 体素 | 26 | 6/26 | 8/26 | **15/26** |

**可以明确说：模型对小病灶很不理想；三次改动只把最难的 ≤ 500 体素档从 0/6 变成 1/6。**

补充一个 `positive_sampling` 独有的现象（评估器 summary 口径的固定分箱，与上面的四分位不同切法）：

| n_ref 区间（体素） | n | 检出 | 召回 | 精确 | pred/ref | pooled Dice |
|---|---:|---:|---:|---:|---:|---:|
| 0–1000 | 16 | 7 | 0.336 | 0.159 | **2.108** | 0.216 |
| 1000–5000 | 27 | 19 | 0.195 | 0.747 | 0.261 | 0.309 |
| 5000–20000 | 15 | 12 | 0.328 | 0.840 | 0.390 | 0.472 |
| > 20000 | 5 | 4 | 0.513 | 0.781 | 0.656 | 0.619 |

> **口径限制（分箱单位）**：分箱只基于 `summary.json` 的**体素数**。validation 导出的逐例参考
> 掩膜位于各例**原始几何**，体素体积逐例不同，因此本表**不能**换算为 mL 或物理体积；物理体积
> 分层需逐例读取 spacing 后计算（full 模式，见第 7 节）。同一更正见
> `docs/experiments/image_gate_positive_sampling.md` §5.5。

> 最小档的 `pred/ref = 2.108`、精确仅 **0.159**，方向与其它三档（`pred/ref < 1`，欠分割）**相反**：
> 该档的"检出"里混入了大量**过预测**。也就是说 ≤ 1000 体素档的检出数提升，**不能**简单读成
> "小病灶分割变好了"。这是本文件目前能给出的最强的小病灶警示。

> **口径限制**：以上只能称为「**病例级病灶负荷分析**」，不能严格称为「小病灶**实例**分析」。
> 一个病例可能含多个病灶，而 `summary.json` 只提供整例的二值分割统计。真正的小病灶结论还需要
> **连通域级别的 lesion-size sensitivity** 分析。

### 3.3 但问题不只发生在小病灶

最大病灶负荷组（7724–123055 体素）在 N0 与 `image_gate` 下都只有 **10/15** 病例产生有效重叠，
**5 例依旧完全漏检**；`positive_sampling` 也只改善到 **12/15**（3 例仍完全漏检）。

因此「小病灶」只能解释一部分失败。其他仍未被排除的可能原因包括：

- 病灶对比度低或多模态表现不一致；
- 标注范围较弥散，而模型只识别最显著区域；
- patch 采样没有充分看到困难阳性病例 —— **这一条已被 `positive_sampling` 部分验证**：
  固定阳性采样确实把完全漏检从 34 降到 21，说明该机制真实存在；但残余的 21 例漏检同时说明
  它**不是唯一原因**，也不足以单独解释剩余失败；
- 病灶概率存在，但没有超过当前 argmax / 决策阈值；
- 病灶位置、形态或强度模式与容易病例不同。

**没有概率图和病灶级审计，目前不能继续区分这些原因。**

### 3.4 检出以后，模型也倾向于只分割病灶核心

在**已经有重叠**的病例中（N0 29 例 / `image_gate` 30 例 / `positive_sampling` 42 例 /
`image_gate_positive_sampling` 40 例），取逐例指标的中位数：

| 指标中位数 | N0（29 例） | `image_gate`（30 例） | `positive_sampling`（42 例） | `image_gate_positive_sampling`（40 例） |
|---|---:|---:|---:|---:|
| 预测体积 / 标注体积 | 0.377 | 0.455 | **0.510** | 0.4546 |
| 病灶体素召回 | 0.353 | 0.376 | **0.458** | 0.3983 |
| 预测精度（`TP / n_pred`，仅该 run 的有重叠病例内部） | 0.889 | 0.839 | 0.879 | 0.8835 |

> **注意这里的样本不是同一批病例**：相对 N0，`positive_sampling` **新增 14 例有重叠**（这 14 例
> 在 N0 中全部为 `n_pred = 0` 的完全无预测病例），同时**丢失 1 例**重叠（11045_1001065），
> 净增 13 例。新增病例多为原本完全漏检的困难病例（见 3.2 节的负担分层），它们是靠"预测了但
> 只覆盖一部分"才进入本表的。因此各列的数字**不能**直接读成"同一批病例被覆盖得更好"；它同时
> 混入了"病例集合本身变宽"这一效应。严格的逐例配对比较、病例集合与 bootstrap 见 §3.8、§3.9
> 与 §3.10。

这是很典型的「**高精度、低召回**」形态：

- 预测出来的区域多数确实位于病灶内；
- 但只覆盖约**三到四成**标注区域；
- 模型更倾向于预测**高置信度病灶核心**；
- 对模糊边缘和低置信度区域缺乏覆盖。

所以除了完全漏检，还存在明显的**欠分割**。

### 3.5 假阳性病例数在前两轮上升、加入 image gate 后小幅回落

严格按照「阴性病例是否出现任何预测体素」统计：

- N0：**11/160** 个阴性病例出现假阳性
- `image_gate`：**17/160**
- `positive_sampling`：**30/160**（接近 N0 的 3 倍）
- `image_gate_positive_sampling`：**27/160**（相对参照臂 `positive_sampling` 回落 3 例，但仍接近 N0 的 2.5 倍）

但假阳性**体积**呈现另一种情况：

| 项 | N0 | `image_gate` | `positive_sampling` | `image_gate_positive_sampling` |
|---|---:|---:|---:|---:|
| 假阳性病例的预测体积中位数 | 1464 体素 | **274 体素** | 534 体素 | 253 体素 |
| 阴性病例假阳性总体积 | 27,294 体素 | 24,625 体素 | **35,178 体素** | 32,575 体素 |
| 阳性区内假阳性体素（ΣFP，仅阳性病例） | 86,833 体素 | 60,878 体素 | 81,547 体素 | **46,001 体素** |

两种模式要分开看：

- `image_gate`（相对 N0）：**病例数略增（11 → 17）、总体积略降（27,294 → 24,625）、中位体积
  降到 274 体素** ⇒ 不是产生了更多大块假病灶，而是**更多阴性病例出现了体积很小的零散预测**；
  同时它把阳性区内的假阳压到原生采样分支最低（60,878 体素）。
- `positive_sampling`（相对 N0）：病例数与**总体积同时上升**（11 → 30 例、27,294 → 35,178 体素），
  中位体积**相对 `image_gate` 从 274 回到 534** ⇒ 它不只是"更多小零散"，还产生了更多**中等体积**
  的假阳；阳性区内假阳也从 `image_gate` 的 60,878 **回升到 81,547 体素**（接近 N0 的 86,833）。
- `image_gate_positive_sampling`（相对参照臂 `positive_sampling`）：病例数 **30 → 27**、总体积
  **35,178 → 32,575 体素**、中位体积 **534 → 253 体素**，阳性区内假阳 **81,547 → 46,001 体素**（四者
  最低）⇒ 在阳性采样条件下加入 image gate **同时降低了阴性假阳与阳性区内假阳**，方向与它在 macro
  Dice 上的「无明确增量」相反，属于**工作点向保守侧移动**（见 §3.10）。

> 这里均值与中位数**方向不一致**，两个都要看：**平均**每例假阳体积在各 run 间持续下降
> （N0 2481 / `image_gate` 1449 / `positive_sampling` 1173 / `image_gate_positive_sampling` 1206 体素），
> 但**中位数**从 `image_gate` 的 274 一度回到 534（`positive_sampling`）再降到 253
> （`image_gate_positive_sampling`）。也就是说："每例平均更小"与"出现了更多中等体积假阳"
> 这两件事在不同 run 上同时成立，只报其中一个都会误导。

因此「假阳性是次要问题」这一判断**只在 N0/`image_gate` 下成立**。到 `positive_sampling`，
假阳已经是一份**必须与敏感度提升一起报告的真实代价**（该 run 在含阴性假阳体素的口径下
`all_prediction_voxel_precision` = 0.6796，**低于** `image_gate` 的 0.7270）。阳性采样条件下
加入 image gate 后该口径回到 **0.7464**（四者最高），阴性假阳与阳性区假阳同时下降；但**这不是**
「假阳问题已解决」：27/160 仍远高于 N0 的 11/160，且该回落伴随 macro Dice 无明确增量（§3.10）。

这可能通过**连通域大小过滤**得到改善，但现在**不能直接设置过滤阈值**——因为小真病灶本来就
已经严重漏检，且 `positive_sampling` 在最小病灶档的 `pred/ref` 高达 **2.108**（过预测），
贸然删除小区域与"过预测"是同一枚硬币的两面，必须先用连通域级分析把两者分开。

### 3.6 早收敛与最终上限是两个不同层面：采样改动第一次同时改善二者

`patch pseudo Dice` **首次达到**某阈值的 epoch：

| pseudo Dice 首次达到 | N0 | `image_gate` | `positive_sampling` |
|---|---:|---:|---:|
| 0.1 | epoch 208 | **epoch 29** | epoch 25 |
| 0.2 | epoch 508 | **epoch 32** | epoch 29 |
| 0.3 | epoch 751 | **epoch 41** | epoch 46 |
| 0.5 | epoch 765 | epoch 123 | **epoch 65** |

分箱均值把两类的**形状差异**显示得更清楚（`patch pseudo Dice` 每 100 epoch 均值）：

| epoch 区间 | N0 | `image_gate` | `positive_sampling` |
|---|---:|---:|---:|
| 0–99 | **0.0040** | 0.0602 | **0.2250** |
| 300–399 | 0.0037 | 0.2754 | 0.4660 |

- N0 是「**前 700 epoch 恒定近零 + 末段阶跃**」（LR 衰减到约 0.003 后才脱离）；
- `image_gate` 与 `positive_sampling` 都是从很早开始**持续上升**；
- `positive_sampling` 的前 100 epoch 均值（0.2250）约为 `image_gate`（0.0602）的 3.7 倍，
  起点上升最快。

但最终全量指标分成了两类：

| 项 | N0 | `image_gate` | `positive_sampling` | `image_gate_positive_sampling` |
|---|---:|---:|---:|---:|
| nnU-Net 汇报 Dice（223 例） | 0.16817 | 0.17025 | 0.20783 | 0.20935 |
| 阳性病例 micro Dice | 0.5212 | 0.5244 | 0.5449 | 0.5397 |
| 阳性病例 macro Dice | 0.1975 | 0.2162 | **0.3068** | 0.2991 |
| 最佳 EMA patch pseudo Dice | 0.5820（epoch 986） | 0.5963（epoch 969） | **0.6157（epoch 792）** | 0.6110（epoch 698） |
| 单 epoch 最高 patch pseudo Dice | 0.7670（epoch 937） | 0.7627（epoch 666） | **0.7810（epoch 999）** | 0.7568（epoch 696） |

因此两类改动的作用层面不同：

1. 训练存在明显的**优化困难与背景局部最优**（N0 的证据：700 epoch 恒定近零）；
2. `image_gate` 只改变了**早收敛**这一个层面 —— 全量 Dice 0.16817 → 0.17025（+0.002），
   micro Dice 与漏检数几乎不动；
3. `positive_sampling` 是**第一次同时改善早收敛与最终漏检指标**（全量 Dice +0.040、
   macro Dice +0.109、漏检 −13）；
4. 但**即使如此，micro Dice 仍停在 0.5449、体素召回仍只有 0.4271** ⇒ 最终上限**没有被突破**，
   只是被抬高了；
5. `image_gate_positive_sampling` 属于**阳性采样这一族**：早收敛同样很快（首个非零 pseudo Dice
   在 epoch 7，前 100 epoch 均值 0.3437，与其参照臂同量级；本 run 自身细节见
   `docs/experiments/image_gate_positive_sampling.md` §4），但最终全量指标与参照臂基本同档
   （macro Dice 0.2991 vs 0.3068，配对 CI 含 0）⇒ 它**没有**在阳性采样之上再抬一次上限。

换句话说：门控让模型「**更快学会**」却没有「**学得明显更好**」；改采样让模型「更快学会**并且**
少漏掉三分之一的阳性病例」，但仍受**检出后覆盖不全**与**假阳增加**限制。

### 3.7 当前在线 validation 指标存在代理偏差

三个 run 的最佳 EMA patch pseudo Dice 都在 **0.58–0.62**（0.5820 / 0.5963 / 0.6157），
但最终全量病例 Dice 只有 **0.17–0.21**（0.16817 / 0.17025 / 0.20783）。

这不是计算错误，而是两种指标**观察的对象不同**：

- **训练期间 pseudo Dice**：只来自有限的 validation patches，且 patch 采样更容易包含前景；
- **最终 validation**：完整 223 例体积，包括大量阴性病例、完全漏检和零散假阳性。

因此**不能**再根据训练中的 pseudo Dice 判断最终模型已经很好。它适合**监控优化过程**，
不适合替代**完整病例或病灶级评估**。

## 4. 综合判断

目前暴露的问题按严重程度排列（数字来自第 2–3 节）：

1. **阳性病例漏检仍然严重**：最好的两个阳性采样 run 也仍有 21–23/63 完全无重叠
2. **小病灶敏感度极低**：≤ 500 体素档仅 1/6 检出，且最小档 `pred/ref = 2.108`（提升里混有过预测）
3. **检出后经常只覆盖病灶核心，存在欠分割**：有重叠病例的召回中位数仅 0.458、`pred/ref` 0.510
4. **病灶体素级匹配度没有被突破**：四个 run 的 micro Dice 都在 0.52–0.55、体素召回 0.39–0.43
5. **假阳性病例数在前两轮上升、加入 image gate 后小幅回落**（11 → 17 → 30 → 27）；到阳性采样
   两个 run，假阳已成为必须与敏感度一起报告的代价
6. **patch 训练指标与全量病例表现不一致**：最佳 EMA 0.58–0.62 vs 全量 Dice 0.17–0.21
7. **存在严重的早期背景收敛问题**：N0 前 700 epoch 恒定近零；`image_gate` 明显缓解、
   `positive_sampling` 基本消除
8. **所有对比都是单次运行**：nnU-Net v2.6.2 不设随机种子，尚不能证明任一改动可稳定复现

已取得的进展（按可归因强度排序）：

| 改动 | 变量类型 | 早收敛 | 最终漏检 / 分割指标 | 代价 |
|---|---|---|---|---|
| `image_gate` | 网络结构（单变量） | 明显改善 | **几乎不动** | 假阳病例 11 → 17 |
| `positive_sampling` | 训练采样（单变量） | **大幅改善** | **明显改善**（漏检 −13、macro Dice +0.109） | 假阳病例 11 → 30、`allPrec` 低于 `image_gate` |
| `image_gate_positive_sampling`（vs `positive_sampling`） | 网络结构（阳性采样分支内，单变量） | 同族（首个非零 epoch 7） | **无明确增量**（配对 delta −0.0077、CI 含 0、漏检 +2） | 体素召回 −0.0282；换来 precision ↑、假阳 ↓（工作点更保守） |

## 5. 全背景塌缩的证据与本项目内的验证结果

`baseline`（N0）与 `optimized_baseline`（原生 Dice+CE）都出现长期停留在全背景预测的现象；后者
的这次运行由用户中止，**不是完成的训练、不是正式模型结果**，只在下面作为**塌缩证据**使用。

现有证据支持：**病例级采样不足 × 极端体素不平衡 × 损失** 共同导致硬前景/全背景塌缩。

- **不能声称采样是唯一原因**：另一个 PI-CAI 项目在「默认 Dice+CE + 固定阳性病例采样」下的早期
  训练 pseudo Dice 仍可长期为零（约 0–0.0003）；说明仅修采样不足以脱离全背景。
  本项目内也有一致迹象：`optimized_baseline`（Dice+CE + **原生采样**）跑到 epoch 377 时最大
  pseudo Dice 仍只有约 0.0008（该运行已中止，只作方向性证据）。
- 同一项目在「Focal+CE + 每批固定一个阳性病灶 patch + 正常长周期 PolyLR」下较早脱离全背景
  （epoch 4 首次非零，epoch 19 约 0.11）。该证据来自另一个项目与另一套预处理，
  只能作为**方向性参考**，不能直接外推为本项目结论。
- 本项目 Dataset605 fold 0 与该项目训练集阳性比例接近（约 28%）、同样 batch size 2、稀疏小病灶。

### 5.1 本项目内的答案（`positive_sampling` 已完成训练与 validation）

本节原先提出的问题：

> **在保持 Focal+CE、网络、增强、optimizer 与 LR 调度完全不变时，固定阳性病例采样能否
> 缩短前景学习延迟并改善小病灶召回？**

**该问题已由 `positive_sampling` 在本项目内完成验证**（单变量：训练 loader 换成每批固定一个
阳性病灶 patch，验证 loader 保持原生）。两个分问的答案不同：

## 6. 本文件的证据边界

- 所有对比均为**单次运行**之间的对比（N0 / `image_gate` / `positive_sampling` 各一次）。
  nnU-Net v2.6.2 **不设置任何随机种子**，三次运行的**权重初始化各自独立**，无法视为受控对照；
  因此上文第 2–3 节描述的是**各实验自身的事实**，不构成「gate 导致 X」「采样导致 Y」的因果结论。
- **配对统计只覆盖病例级重采样**：§3.8 的配对 bootstrap 置信区间是在**同一次运行内**对 63 个
  阳性病例重采样得到的，**不覆盖 run-to-run 方差**。CI 不含 0 只能说明该 fold 内逐病例配对差异，
  不能用来宣称某个改动带来了确定幅度的提升或可跨 seed 复现。
- **历史 gate 结论的范围**：`image_gate`「只改早收敛、未改最终上限」的结论只在 **N0 ↔
  `image_gate` 同属原生采样**的配对中成立；它不是所有已完成实验的一般结论，也不得外推到
  阳性采样分支。`image_gate` → `positive_sampling`（§3.8(c)）同时混入网络与采样两个变量，
  不能作单变量归因。
- **指标的岗位分工**：`patch pseudo Dice` 只描述**优化过程**，不适合替代完整病例评估；
  本文件的最终结论一律基于全量 223 例的 validation 指标。两者差距见第 3.7 节。
- **不同 run 的"有重叠病例"集合不同**：第 3.4 节的三列不是同一批病例（相对 N0，
  `positive_sampling` 新增 14 例有重叠——这 14 例在 N0 中全部完全无预测——同时丢失 1 例，
  净增 13 例，见 §3.8 / §3.9），跨列比较时同时混入了"病例集合变宽"这一效应。
- 第 3.2 节的分组是**病例级病灶负荷**，不是病灶实例级分析。
- 第 3.3 节列出的替代原因在取得**概率图与病灶级标注统计**之前无法进一步区分。
- 第 3.7 节的结论仅针对指标口径，不涉及模型能力判断。
- 本文件不包含 `anatomy_gate_positive_sampling` 与 `feature_*_positive_sampling` 的任何结果；
  它们的输出目录尚未创建。`image_gate_positive_sampling` 已完成训练与 validation，其结论只在
  §3.10 按 §5.3 预先固定的判据给出。
- §3.10 的配对结果同样受「单次运行、无随机种子、CI 不含 run-to-run 方差」约束：**不得**写成
  「gate 无效」或「gate 降低性能」，只能陈述本 fold、本次运行观察到的方向与代价。
